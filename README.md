📖 About This Repository

This repository is a centralized academic resource hub containing notes, reference materials, and syllabus information for B.Tech Computer Science & Engineering students.

The goal is simple: make important study materials organized, accessible, and easy to find in one place.

Whether you're preparing for internal examinations, semester examinations, assignments, or revising important concepts, this repository provides a convenient collection of subject-wise resources.

University: Jawaharlal Nehru Technological University Hyderabad (JNTUH)

Program: Bachelor of Technology — Computer Science & Engineering

Regulation: R22
